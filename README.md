# ShopEase

A simple, responsive e-commerce demo built with React and Vite.

## Features
- 5 products with illustrated images, prices in ₹, star ratings and Add to Cart
- Search by name and category filter
- Cart drawer with quantity controls, remove, item count, subtotal and checkout
- Mobile-first layout with a mobile menu

## Run locally
```bash
npm install
npm run dev      # start dev server
npm run build    # production build
```
